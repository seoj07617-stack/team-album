# 球队相册

球队家长与孩子的在线相册，GitHub Pages 托管，手机浏览器直接打开，无需安装任何应用。

## 访问
- 地址：https://seoj07617-stack.github.io/team-album/
- 进入需输入访问密码，密码在球队家长群内同步；输入一次后 30 天内免输入

## 上传照片（GitHub 网页端）
1. 登录 GitHub，打开本仓库 https://github.com/seoj07617-stack/team-album
2. 进入 uploads 文件夹，点进目标相册（如 比赛现场）
3. 右上 Add file → Upload files，把照片拖进去
4. 底部 Commit changes 提交
5. 约 1-2 分钟后相册自动出现新照片，无需改任何代码

## 新建相册
在 uploads 下新建文件夹即可（文件夹名就是相册名，如 2026春季联赛），文件夹内放入照片后首页自动出现该相册。

## 修改访问密码
1. 用任意 SHA-256 在线工具计算新密码，得到 64 位十六进制字符串
2. 编辑 index.html，找到 PASSWORD_SHA256，替换其值
3. 提交后约 1 分钟生效，家长需重新输入新密码

## 界面说明（抽屉版）
- 顶部紫色栏 + 左上角菜单按钮打开抽屉，抽屉里可按「全部 / 集体照 / 训练照 / 比赛照 / 个人照」分类浏览，显示各类照片数
- 首页为概览卡 + 分区相册：每个相册一张卡，照片以九宫格展示，点击进入大图模式
- 新建的相册（uploads 下的新文件夹）会自动出现在首页和抽屉里
- 手机浏览器菜单里选"添加到主屏幕"，即可像 App 一样打开（图标为队徽）

## 注意事项
- 相册内容涉及未成年人照片，链接与密码请勿发到球队以外的任何群
- 苹果手机拍摄的 HEIC 原片部分手机无法显示，建议转 JPG 或 PNG 后再传
- 大图浏览：左右滑动切换，下划关闭，长按照片可保存
- 单张照片建议不超过 10MB；仓库整体建议保持在 1GB 以内（约两千张压缩过的手机照片）

## 安全须知（重要）
- **密码只是网页门禁**：本仓库在 GitHub 上是公开的，懂 GitHub 的人可以直接浏览仓库里的照片文件。请勿上传特别敏感的照片（如含证件、姓名班级、住址信息的）。
- 密码请设置得复杂些（字母+数字混合、8 位以上），不要用"球队名+年份"这类容易被猜到的组合，并建议每学期更换。
- 更换密码后记得同步到家长群。

## 定期备份（照片永久保存的关键）
GitHub 上这份只是拷贝之一，不要把鸡蛋放在一个篮子里：
1. 每学期结束后，打开仓库页面 → 绿色 Code 按钮 → Download ZIP，把全部照片打包存到自己的电脑或移动硬盘
2. 重要比赛的原片，建议在上传前就本地留存一份
3. 若哪天 GitHub 访问不稳或仓库过大，可迁移到国内对象存储（如腾讯云 COS）或自建相册，需要时可再寻求帮助
